# sheaf-persistence-bundle

**Multi-parameter persistent homology via sheaf theory** — computes persistence beyond single-parameter filtrations using sheaf-theoretic constructions.

## What This Gives You

- **Multi-parameter persistence** — filtrations parameterized by multiple dimensions
- **Sheaf cohomology** — compute cohomology groups over sheaves on posets
- **Stability theorems** — provable stability of multi-parameter persistence
- **Visualization** — persistence diagrams and barcode plots for multi-parameter settings

## How It Fits

Extends `betti-music-computation` from single-parameter to multi-parameter persistence. Theoretical foundation for `conservation-tomography`'s multi-dimensional analysis.
